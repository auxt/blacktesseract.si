# blacktesseract.si

An interactive tour of TESSERACTα (TesseractAlpha), a self-evolving research organism for crypto perpetual markets.

- `index.html`: the tour. Everything on it is illustrative and generated in the browser.
- `charts/`: the Live markets section. TesseractCharts' chart engine (`chartpro.js`, `studies.js`, `ta.js`) fed straight from Hyperliquid's public API in the visitor's browser (`site-charts.js`). Public market data only.

Fonts: Orbitron, Rajdhani and Share Tech Mono, embedded under the SIL Open Font License 1.1 (see `FONTS-LICENSE.txt`).
